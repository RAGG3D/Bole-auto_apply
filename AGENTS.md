# Bole repository

For job-search or resume tasks, read SKILL.md and only the references for the requested mode.
For Bole Lite, read bole-lite/SKILL.md. Claude commands are thin wrappers, not separate rules.
For development, preserve user changes and run `python3 scripts/ats_lint.py` and
`python3 -m unittest discover tests`. Never commit profile/, Applications/, state/ or private logs.
